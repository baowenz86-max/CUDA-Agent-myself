## 2. 为什么先解决数据问题？

强调反编译是恢复等价实现，不是还原唯一源码。PTX 是虚拟指令集，SASS 是硬件机器指令；两者的难度和输入信息不同，需要分别评估。

依据：论文 §I–II，PDF pp.1–3

## 3. PtxDec：数据、表示与训练协同

论文采用两条互补的编译器增强路线：Ansor 扩大调度多样性，Welder 扩大子图多样性。之后清理冗余括号、抽取索引公共子表达式并去重。Rolled-PTX 通过循环重卷降低输入复杂度。注意这些是论文方法，我的系统目前没有实现这些模块。

依据：论文 §III，PDF pp.4–7；§IV-F，p.10（Fig.14）

## 4. 论文结果说明什么？

表格均来自论文，不是我的实验结果。主实验是从 40 万对数据中随机抽取 4000 个测试样例；移除重构或重卷都会显著降低 I/O 正确率。域外结果提示仅有同分布高分并不足够。论文以 CodeBLEU 作为可读性代理，以延迟和访存效率偏差衡量调度一致性。

依据：论文 Tables I–IV，PDF pp.8–10；主测试集 4,000 kernels
